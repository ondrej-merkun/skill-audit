# Repository social preview

Use `docs/social-preview.png` as the GitHub repository social preview image.
It is a 1280x640 PNG under 1 MB, matching GitHub's recommended best-display
size for repository preview cards.

## Upload steps

1. Open the repository on GitHub.
2. Go to **Settings**.
3. In **Social preview**, choose **Edit**.
4. Upload `docs/social-preview.png`.
5. Save the settings and share the repository URL in a preview checker or
   private draft post to confirm the card renders with the custom image.

GitHub documents PNG, JPG, and GIF uploads under 1 MB, with 1280x640 as the
recommended best-display size.
